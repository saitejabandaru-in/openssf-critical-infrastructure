# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please report it privately. **Do not disclose it publicly until a fix has been released.**

Please report security vulnerabilities by emailing [security@saitejabandaru.com](mailto:security@saitejabandaru.com). 

We aim to respond to all reports within 48 hours and provide a resolution plan within 5 business days.

## OpenSSF Scorecard
This project uses the OpenSSF Scorecard GitHub Action to automatically assess its security posture. The results are published to the Security tab and are used to continually improve our security practices.
